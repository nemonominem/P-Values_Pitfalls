# BayesNotes

This repository contains notes and reference material for an article on p-values, false positive risk, and Bayesian alternatives.

## Contents

- `p-values-pitfalls.md` — main markdown article draft.
- `articles/` — reference PDFs cited by the article.
- `p-values-images/` — local image assets used in the markdown.
- `reviews/` — review notes and fact-check results.

## Notes

- External image links in `p-values-pitfalls.md` have been replaced with local references in `p-values-images/`.
- The `reviews/` folder contains review files with timestamps and reviewer metadata.

## Usage

- Edit `p-values-pitfalls.md` to update the article.
- Keep image assets in `p-values-images/` and reference them with relative paths.
- Add supporting papers to `articles/` and update the references section in the markdown as needed.

## Review

A review of the article is stored in `reviews/` with the filename format:

- `review-YYYY-MM-DD-HHMMSS.md`

The review includes numeric verification of the article's FPR claims and a note on one potential discrepancy.
